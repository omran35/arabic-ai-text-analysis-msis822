# مجلدات البيانات

- raw/: نسخة المصدر دون تعديل، تنشأ عند تشغيل الدفتر.
- processed/: ناتج ضبط الجودة والنصوص المعالجة وخريطة تقسيم المصدر.
- external/: قائمة كلمات الوقف والموارد الخارجية والكاش.

النسخ الكبيرة قابلة لإعادة الإنشاء من مصدر Hugging Face المثبت في الدفتر ومستثناة من Git.
أحفظ النص الأصلي منفصلًا حتى أراجع أثر التنظيف وأحسب علامات الترقيم قبل حذفها.
وصف الأعمدة وملفات النتائج موجود في docs/FILES_AND_TERMS_AR.md.
