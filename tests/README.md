# اختبارات تنظيم المشروع

من جذر المستودع بعد تثبيت `requirements.txt`:

```bash
python -m unittest discover -s tests -v
```

الاختبارات لا تنزل بيانات. تغطي التطبيع، وفحص الأعمدة، وحفظ معلومات المصدر،
وعزل النصوص غير الصالحة، وحماية التقسيم من التسرب، وحدود العبارات والإحصاءات.
وتفحص خلية إعداد Colab بمحاكاة التنزيل والتثبيت حتى لا تعتمد على الشبكة.

فحص التشغيل على البيانات الكاملة موثق في [سجل التحقق](../docs/REFACTOR_VALIDATION_AR.md).
