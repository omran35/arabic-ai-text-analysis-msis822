# مكان الوحدات البرمجية

وظائف المرحلتين 1 و2 موجودة داخل الدفتر المعتمد ليعمل مستقلًا في Colab.
عندما أبدأ إضافة بقية المراحل يمكن استخراج الدوال المشتركة هنا:

- data_preparation.py: التحميل وضبط الجودة والمعالجة وإعداد الخصائص عند تنفيذها.
- visualization.py: الرسوم والمقارنات.
- utils.py: المسارات والحفظ والإعدادات العامة.
- modeling.py: تدريب النماذج وتقييمها عند تنفيذ المرحلة الرابعة.

هذه أسماء مقترحة للتنظيم اللاحق وليست ملفات تنفيذ موجودة حاليًا.
