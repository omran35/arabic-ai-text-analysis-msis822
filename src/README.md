# الدوال البرمجية المساندة

هذا المجلد يحتوي على دوال مستخدمة في المعالجة العربية وأدوات الحفظ والتنظيم.
يحتفظ دفتر Colab بنسخته المستقلة من الدوال حتى يعمل عند فتح ipynb وحده دون تنزيل ملفات أخرى.

| الملف | الموجود فيه |
|---|---|
| data_preparation.py | توحيد Unicode والمسافات، تطبيع العربية، قائمة الوقف، حذف الوقف وتجذير ISRI |
| visualization.py | ضبط اتجاه العربية للرسوم وحفظ الأشكال |
| utils.py | إعدادات المصدر والبذرة ونسخة البيانات وتجهيز مجلدات المشروع |
| __init__.py | تعريف src كحزمة Python |

طابقت مخرجات المعالجة مع أمثلة Human وAI المحفوظة في جداول المرحلة الثانية؛ تطابقت النسخ الثلاث
لكل الأمثلة الأربعة. واختبرت حالات النص غير المتاح والفصل بين الكلمات والحروف المحفوظة والمسافات.
استيراد الوحدات لا ينزل أي بيانات. تنزيل قائمة NLTK يحتاج طلبًا صريحًا عبر download=True.

مثال عند تشغيل Python من جذر المستودع بعد تثبيت المتطلبات:

```python
from src.data_preparation import get_arabic_stopwords, preprocess_text

stop_words = get_arabic_stopwords('data/external/nltk_data', download=True)
versions = preprocess_text('إِنَّ هَذِهِ دِرَاسَةٌ عَرَبِيَّةٌ.', stop_words)
print(versions)
```

إعداد الخصائص وتدريب النماذج لم ينفذا. أضيف وظائفهما وملف modeling.py عند تنفيذ المرحلتين
الثالثة والرابعة، بدل وضع كود فارغ يوحي بوجود نموذج جاهز.
