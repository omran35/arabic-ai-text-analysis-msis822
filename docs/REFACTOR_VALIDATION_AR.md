# فحص فصل الدوال عن النوت بوك

تاريخ الفحص: 21 أكتوبر 2026.

انتقل تنفيذ المرحلتين إلى `src`، وبقيت في الدفتر الاستدعاءات والشرح والمخرجات.
لم تتغير نسخة المصدر أو البذرة أو قواعد التنظيف والتقسيم أو مقامات التكرار.

- شُغلت خلايا التنفيذ الأربع عشرة محليًا باستخدام البيانات الكاملة من الكاش،
  بنفس نسخة المصدر `584e43a346914a4cb1a51f9679f903284b65c36e`.
- طابقت جداول CSV العشرون الجداول المنشورة السابقة تمامًا بعد قراءتها، بما فيها القيم العشرية.
- طابق ملف `phase1_audit.json` والتقرير النصي المخرجات السابقة تمامًا.
- تولدت الرسوم العشرة وZIP النتائج، وحُفظت المخرجات الجديدة داخل الدفتر.
- بقي 36,478 نصًا صالحًا، منها 25,577 نص تدريب للتحليل اللغوي.
- نجحت اختبارات التطبيع وحدود الكلمات، وتحميل CSV، وعزل التعارض والنقص،
  وحفظ المصدر، وعدم تسرب مجموعات المصدر، وحدود n-grams وإحصاءات النص الأصلي.
- فُحصت خلية إعداد الدفتر من جذر المستودع ومن `notebooks` ومن مجلد جلسة جديد،
  مع التحقق من عدم الكتابة فوق تعديلات الجلسة عند إعادة تشغيلها.

فحص الإعداد حاكى استنساخ المستودع وتثبيت المكتبات. التشغيل الكامل استخدم المكتبات
المثبتة محليًا وقائمة NLTK المحفوظة وبيانات Hugging Face من الكاش، دون إعادة تنزيلها.
هذا تحقق محلي؛ لم يُشغّل هذا الإصدار داخل جلسة Google Colab فعلية أثناء هذا الفحص.

تشغيل الاختبارات بعد تثبيت `requirements.txt`:

```bash
python -m unittest discover -s tests -v
```
