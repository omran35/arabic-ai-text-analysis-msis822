# مطابقة متطلبات المرحلتين الأولى والثانية — MSIS822

المطابقة مبنية على صفحة 3 من تعليمات مشروع المقرر، مع تنظيم ملفات التسليم بما يلائم
النطاق الحالي. الدفتر المعتمد هو [phases_1_2_preprocessing_eda.ipynb](../notebooks/phases_1_2_preprocessing_eda.ipynb).

| المتطلب | موضع التنفيذ والدليل |
|---|---|

| 1.2 تحميل البيانات باستخدام datasets | القسم 1.2 في الدفتر و`src/data_preparation.py`؛ المصدر مثبت بـrevision |
| 1.3 أسماء الأعمدة وأنواعها | `reports/tables/phase1_schema.csv` |
| 1.3 توزيع النصوص البشرية والمولدة | `phase1_class_distribution.csv` والرسم الموافق، قبل التنظيف وبعده |
| 1.3 النقص والتكرار وعدم الاتساق | `phase1_raw_quality.csv` و`phase1_audit.json` وجداول الحالات المعزولة |
| 2.1 تطبيع العربية وإزالة التشكيل والحروف غير العربية | `src/data_preprocessing.py` والقسم 2.1 وأمثلة قبل المعالجة وبعدها |

| 2.2 متوسط طول الكلمات والجمل وTTR | `phase2_linguistic_summary.csv` ورسوم المقارنة والتوزيع |

## حزمة المراجعة

- دفتر واحد يجمع الاستدعاءات والشرح والمخرجات المحفوظة.
- تقرير نتائج، و8 رسوم، و20 جدول CSV وملف تدقيق JSON.
- ملفات Python مقسمة حسب التحميل والمعالجة والتحليل والعرض والحفظ.
- منهجية وقاموس بيانات ومعلومات بيئة التشغيل، مع اختبار المعالجة وإعداد الدفتر.

حجز مجموعات التحقق والاختبار مبكرًا إجراء وقائي قبل الاستكشاف، استنادًا إلى تنبيه
منع التسرب في التعليمات. نطاق هذا التسليم يقتصر على المرحلتين الأولى والثانية؛
لا يتضمن نماذج مدربة أو تقرير المشروع النهائي أو العرض الخاص بالمراحل اللاحقة.
