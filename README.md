## ماذا وجدت في المرحلتين؟

- مصدر البيانات يضم 8,388 صفًا، وفيها 41,940 خانة نص قبل التنظيف.
- عزلت 4 نصوص بلا حروف عربية، و117 وقوعًا متعارض التصنيف بعد التطبيع.
- حذفت 5,341 تكرارًا كاملًا وفق قاعدة توحيد Unicode والمسافات، مع حفظ معلومات المصدر.
- بقي 36,478 نصًا صالحًا فريدًا: 2,961 بشريًا و33,517 مولدًا.
- أجريت التحليل اللغوي على 25,577 نص تدريب؛ بقي التحقق والاختبار محجوزين.
- حفظت 10 رسوم و20 جدول CSV، إضافة إلى ملف تدقيق JSON وتقرير النتائج.

عدد نصوص AI أكبر، لذلك قارنت تكرار الكلمات بمعدلات نسبية داخل كل فئة.
الفروق وصفية لهذا المصدر؛ لم أنفذ نماذج كشف أو أحسب دقة تصنيف في هذا الجزء.

## كيف نظمت المشروع؟

```text
notebooks/                 الدفتر الحالي، وملفات تخطيط المراحل اللاحقة
data/raw/                  بيانات المصدر كما هي؛ تنشأ عند التشغيل
data/processed/            بيانات المعالجة وخريطة التقسيم؛ تنشأ عند التشغيل
data/external/             كلمات الوقف والموارد المساندة؛ تنشأ عند التشغيل
src/                       موضع الوحدات البرمجية عند تنظيم الكود لاحقًا
models/                    موضع النماذج المحفوظة بعد تنفيذ المرحلة الرابعة
reports/figures/           الرسوم الحالية
reports/tables/            جداول الجودة والإحصاءات الحالية
reports/presentations/     موضع العرض النهائي بعد المرحلة الخامسة
docs/                      ملاحظات الفهم، وصف الملفات، الخطة، ومراجعة المرحلة الأولى
requirements.txt           مكتبات التشغيل بنطاقات متوافقة
requirements-tested.txt    إصدارات بيئة الاختبار المحلي
```

وظائف المرحلتين موجودة داخل الدفتر ليعمل مستقلًا في Colab. [فهرس الدفاتر](notebooks/README.md).
الملف `01_Phase1_Exploration.ipynb` نسخة سابقة محفوظة للرجوع إليها؛ الدفتر المعتمد هو الرابط في الأعلى.
[مراجعة النسخة السابقة](docs/phase1_review_ar.md).
