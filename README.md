## التشغيل على Google Colab

1. افتح زر **Open in Colab** أعلاه، واختر بيئة Python عادية؛ CPU يكفي.
2. شغّل خلية الإعداد أولًا، ثم **Runtime > Run all**. تجلب الخلية المستودع وتثبت مكتباته وتجهز استيراد `src` تلقائيًا.
3. انتظر اكتمال الخلايا بالترتيب؛ يحتاج التشغيل اتصالًا لتحميل المكتبات والبيانات وقائمة كلمات الوقف. المصدر العام لا يتطلب رمز Hugging Face.
4. تجد مخرجات الجلسة داخل `arabic_text_analysis_outputs/`. آخر خلية تنشئ `msis822_phases_1_2_results.zip` للتقرير والرسوم والجداول ومعلومات التشغيل.
5. لتنزيل الحزمة من Colab، أزل التعليق عن سطري `files.download` في آخر خلية. احفظ النتائج قبل انتهاء الجلسة لأن تخزين Colab مؤقت.

يمكن أيضًا فتح الدفتر محليًا من جذر المستودع أو من `notebooks/` وتشغيل الخلايا بالترتيب.
`requirements.txt` يحدد مكتبات التشغيل، و`requirements-tested.txt` يسجل الإصدارات التي اختُبرت محليًا.

والكاش تُنشأ عند التشغيل وتُستثنى من Git؛ تبقى النتائج الصغيرة محفوظة للمراجعة.

## أبرز النتائج

- 8,388 صفًا أصليًا تحتوي على 41,940 خانة نص.
- عزل 4 نصوص بلا حروف عربية و117 وقوعًا متعارض التصنيف بعد التطبيع.
- إزالة 5,341 تكرارًا كاملًا؛ المتبقي 36,478 نصًا: 2,961 بشريًا و33,517 مولدًا.
- إجراء التحليل اللغوي على 25,577 نص تدريب، مع حجز مجموعات التحقق والاختبار مبكرًا.
- متوسط الكلمات: 118.39 للبشري و100.97 للمولد؛ متوسط طول الجملة: 54.84 مقابل 21.19 كلمة وفق تقسيم تقريبي بالترقيم.

المقارنات وصفية لهذا المصدر، وتراعي اختلاف حجم الفئتين باستخدام معدلات نسبية.
لا تشمل المرحلتان الحاليتان تدريب نموذج أو قياس دقة الكشف.
